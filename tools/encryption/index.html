Text encryption

Protect a short piece of text with a passphrase. Generate an encrypted token or decrypt a token using the same passphrase.

Experimental utility — not audited for sensitive information

For demonstration and non-sensitive test text only. Do not use this public website for clinical records, personal identifiers, passwords, confidential documents or regulated data. It has no account, key recovery, or institutional security approval.

Encrypt or decrypt

Runs in your browser

Up to 8,192 characters. Use non-sensitive sample text.

The passphrase is never saved by this page. Losing it means losing access to the encrypted text.

Clipboard managers and clipboard history may retain copied tokens.

How it works

This is a static page with no backend, analytics, cookies or local storage. The application uses the browser Web Crypto API: PBKDF2-HMAC-SHA-256 for key derivation and AES-256-GCM for encryption.

Each encryption produces a different token, even for the same text and passphrase. This is expected. Tokens start with ENC1.; they are not compatible with tokens from earlier specialized prototypes.

Security and technical limitations
  • 600,000 PBKDF2 iterations; random 16-byte salt and 12-byte AES-GCM nonce per encryption; 128-bit authentication tag.
  • Processing occurs locally once page assets have loaded. The application code makes no network requests.
  • Text is not written to cookies, local storage or browser databases. Results clear when the tab is hidden or closed; decrypted output also clears after 30 seconds.
  • A public website, malicious browser extension, compromised computer, altered hosting content or clipboard history are outside the protection provided by this utility.
  • Encryption is not anonymization and does not replace access controls, approved key management, backup or institutional data-governance procedures.
